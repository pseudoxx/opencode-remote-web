## 🌟 Highlights

- 📱 **Mobile & PWA Ready**: Optimized for mobile and desktop viewports alike. Installable as a standalone Progressive Web App with offline shell caching.
- ⚡ **Seamless Pairing**: Pair effortlessly using your phone's camera to scan the terminal QR code generated by `opencode pair`, paste a one-time connection link, or log in directly with server credentials (supporting LAN, Tailscale, or tunnels).
- 💬 **Live Streaming Chat**: Real-time assistant streaming with formatted markdown, collapsible agent reasoning / thinking blocks, and tool status chips.
- 🛡️ **Interactive Tool Approvals**: Receive instant approval prompts for sensitive operations (shell execution, file writes) and answer agent multiple-choice questions right from your phone.
- 🔍 **Diff Viewer & Checkpoints**: Inspect file modifications, revert turns, and undo reverts safely.
- 📄 **Clean Markdown Export**: Export complete conversation histories to formatted Markdown with sanitized code fences and tool summaries.
- 🔌 **Universal Compatibility**: Works out of the box with both OpenCode 2.x and OpenCode 1.x servers.

## 🚀 Quick Start

### 1. Pairing with your OpenCode Server

1. Start your OpenCode server or run pairing in your project directory:
   ```bash
   opencode pair
   ```
2. Open OC Remote in your browser:
   - **QR Code**: Tap "Scan QR" and point your camera at the QR code in the terminal (or upload a screenshot of it).
   - **Pairing Link**: Paste the generated connection link (`http://<host>:<port>/auth/connect/<token>`).
   - **Password Login**: Switch to the "Password" tab and enter your host address and server password.

## 🛠️ Local Development & Testing

The repository includes a self-contained local playground and test suite that runs without needing external cloud AI providers:

### Local Mock Playground
Launch a local mock LLM along with an OpenCode test server:
```bash
node dev/lab.mjs
```
This sets up an isolated mock environment and outputs a single-use pairing link for immediate browser testing.

### End-to-End & Unit Tests
Run the Playwright test suite:
```bash
npx playwright test
```
- `tests/unit.spec.ts`: Pure logic tests for address parsing, pairing token decoding, and markdown export.
- `tests/app.spec.ts`: End-to-end browser flows for pairing, live streaming, permission prompts, and dark mode.
- `tests/qr.spec.ts`: QR code camera scanner and image upload decoding tests.
- `tests/v1.spec.ts`: Compatibility tests with OpenCode 1.x servers.

### Smoke Tests & Screen Capture
```bash
node dev/smoke.mjs [outputDir]
node dev/screens.mjs <pairingLink> [outputDir]
```
